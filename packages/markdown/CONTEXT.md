# Markdown Package Context

## Domain
The core CodeMirror 6 extensions for Markdown editing.

## Responsibilities
- Construct the base `markdown()` language extension.
- Provide custom syntax highlighting, active line styling, block styling.
- Manage line-wrapping and basic layout extensions.

## Ubiquitous Language
- **CodeMirror Extension**: An isolated piece of behavior injected into `EditorState`.
